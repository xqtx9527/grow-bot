# 国内连接器

在「设置 → 连接器」点击加号，按弹出的官方网页登录并同意授权，软件自动完成连接。无需获取或粘贴 API Key、Client ID、Token 或 MCP 地址。

- 得到大脑：浏览器设备授权，页面可能要求核对软件显示的验证码。仍需要得到大脑会员。
- 知识星球：使用官方 CLI 的浏览器设备授权，页面可能要求核对验证码。官方 CLI 管理授权；断开连接只停用 Grow Bot 工具，不退出其他软件共用的官方 CLI 账号。
- 百度网盘：在独立登录窗口完成官方个人体验授权，Grow Bot 接收 OAuth 回调。个人体验限制仍由百度控制，不含本地文件上传。

已有密钥配置保持兼容。要切换登录方式，可先断开，再点击连接。

实现未修改 DSH：得到大脑授权写入原有秘密存储，知识星球复用官方 CLI 安全存储，百度网盘仅捕获官方 OAuth 回调，不读取登录页密码或 Cookie。

已验证模拟授权、取消、插件与桌面测试；真实账号授权需要用户本人完成。
